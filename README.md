# Rematch

---

**Rematch**  
*AI-powered resume and candidate matching for job seekers and recruiters.*

---

## ✦ Why Rematch?

Rematch bridges the gap between great talent and great companies. Powered by advanced AI—including OpenAI and custom algorithms—Rematch helps:

- **Job Seekers:**  
  Instantly analyze your resume against a job description. Get a clear match score, see your strengths, and pinpoint what’s missing.
- **Recruiters/Hiring Managers:**  
  Rank candidates in seconds. Upload resumes and a job description, and Rematch delivers an ordered shortlist, ready for export.

---

## ✦ What You Get

| For Job Seekers       | For Recruiters & Hiring Managers        |
|-----------------------|-----------------------------------------|
| Resume match scoring  | Bulk resume ranking                     |
| Skill gap analysis    | AI-powered candidate sorting            |
| Actionable feedback   | Export to CSV/Excel                     |

---

## ✦ How Rematch Works

1. **AI Matching**  
   Uses OpenAI’s API and proprietary algorithms for precise matching.

2. **Scoring & Feedback**  
   Resume/job analysis with actionable advice.

3. **Bulk Ranking**  
   Instantly rank any number of resumes for a job.

4. **Export**  
   Download your results to CSV or Excel.

---

## ✦ Get Started

**Requirements:**
- Node.js (LTS recommended)
- npm or yarn
- OpenAI API key

**Installation:**
```bash
git clone https://github.com/jinobaby/AI-ReMatch.git
cd AI-ReMatch
npm install
```

---

## ✦ How To Use Rematch

### For Job Seekers

- Upload your resume and the job description.
- Get your match score and improvement tips.

### For Recruiters

- Upload job description and candidate resumes.
- View instant rankings.
- Download results for review.

**Sample Usage:**
```js
import { analyzeResume } from 'rematch-core';

const score = analyzeResume('resume.pdf', 'job-description.txt');
console.log(score);
```

---

## ✦ Configuration

- Set your OpenAI API key in environment variables.
- Adjust role settings in `config/roles.json`.
- Choose export format in the settings panel.
