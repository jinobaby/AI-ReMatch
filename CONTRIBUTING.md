# Contributing to Rematch

Thank you for your interest in contributing to Rematch!  
We welcome improvements, bug fixes, suggestions, and new features from the community.

---

## Ways to Contribute

- **Report Bugs:**  
  Found an issue? Please open a [GitHub Issue](https://github.com/jinobaby/AI-ReMatch/issues) with details and steps to reproduce.

- **Suggest Features:**  
  Have an idea for Rematch? Propose it in the issues or start a discussion.

- **Submit Pull Requests:**  
  Fix bugs, add features, or improve documentation. See below for steps.

- **Improve Documentation:**  
  Help make Rematch easier to use by clarifying instructions, examples, or guides.

---

## Getting Started

1. **Fork the Repository**  
   Click "Fork" at the top-right of the repo page to create your copy.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/<your-username>/AI-ReMatch.git
   cd AI-ReMatch
   ```

3. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Install Dependencies**
   ```bash
   npm install
   ```

5. **Make Your Changes**  
   Follow code style and conventions.

6. **Commit and Push**
   ```bash
   git add .
   git commit -m "Describe your changes"
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**  
   Go to your fork on GitHub and click “Compare & pull request.”

---

## Pull Request Checklist

- Provide a clear description of your changes.
- Reference related issues (if any).
- Ensure your code passes tests and linting.
- Do not include sensitive information in your PR.
- For major changes, please discuss in issues before submitting.

---

## Code Style

- Use clear variable and function names.
- Follow the existing code formatting.
- Write comments for complex logic.

---

## Community Guidelines

- Be respectful and constructive.
- Discuss large changes in issues first.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md) (if available).

---

## Need Help?

If you have questions or need guidance, open an issue or contact the repo maintainer via [GitHub Discussions](https://github.com/jinobaby/AI-ReMatch/discussions).

---

Thank you for helping make Rematch better!
